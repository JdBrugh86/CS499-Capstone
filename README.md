# Jonathan Brugh — CS-499 ePortfolio

Source for my CS-499 Computer Science Capstone ePortfolio, built with Jekyll and the `minima` theme, hosted via GitHub Pages.

**Live site:** https://jdbrugh86.github.io/Jonathan-Brugh-ePortfolio/

## Contents

- Home — project overview and navigation
- Professional Self-Assessment
- Code Review of the original artifact
- Enhancement One — Software Design and Engineering
- Enhancement Two — Algorithms and Data Structures
- Enhancement Three — Databases

All code artifacts referenced in this ePortfolio live in the companion repository: [CS-499_Capstone](https://github.com/JdBrugh86/CS-499_Capstone).

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000/Jonathan-Brugh-ePortfolio/`.
